# Bot Binance + WhatsApp (Render 24/7)

Bot que detecta compras masivas en Binance y permite comprar 100€ o 200€ vía WhatsApp Cloud API.

## Variables de entorno necesarias

- API_KEY
- API_SECRET
- WHATSAPP_TOKEN
- PHONE_ID
- NUMERO

## Deploy en Render

1. Crear Web Service
2. Build command: `npm install`
3. Start command: `npm start`
4. Añadir variables de entorno
5. Conectar webhook de WhatsApp a `/webhook`
